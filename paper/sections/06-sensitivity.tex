\subsection{模型的优缺点}

\textbf{优点:}
\begin{itemize}
\item \textbf{无负样本条件下的统一框架}。通过“存在性分类归约为检测”的方案,绕开了训练集与验证集均无负样本的困境,使问题一与问题二共用同一检测模型,端到端、易部署。
\item \textbf{针对数据难点的定制设计}。针对小目标与多尺度引入 $P_2$ 检测头、$1280$ 高分辨率输入与强数据增强,针对类别不平衡引入类别加权损失,并由消融实验验证其正向贡献。
\item \textbf{全面的评估体系}。从准确性、鲁棒性、效率、可解释性四个维度评估,辅以对比、消融与灵敏度实验,结论相互印证、可复现。
\end{itemize}

\textbf{缺点:}
\begin{itemize}
\item \textbf{合成负样本的分布偏差}。问题一评估所用的负样本由无残损区域拼合而成,与真实无残损集装箱图像可能存在分布差异,导致误报率与精度指标偏乐观;若后续获得真实负样本,应重新校准阈值与指标。
\item \textbf{阈值选择与评估同集}。$\tau$ 的选择与分类指标报告在同一验证集上完成,存在轻微过拟合;训练期已从训练集划出独立验证集用于早停以缓解,更严格的做法是引入额外的留出集。
\item \textbf{严重度代理的近似性}。官方未给出严重度定义,本文以边界框面积 $w_i h_i$ 作为代理,可能与真实排序口径存在偏差;该近似的影响已在 top-4 排序对比(表~\ref{tab:q3-top4})中量化。
\item \textbf{泛化边界}。模型基于当前集装箱外观训练,迁移到新型箱体、极端天气或不同相机视角时需再标注微调。
\end{itemize}
