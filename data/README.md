## 关键事实(影响建模)
1. **训练集无"无残损"图片**:train 3300 张、test 413 张**空标签文件数均为 0**,每张图至少 1 个标注 → 无法训练有监督二分类器,"是否残损"只能靠检测模型的"有无框"隐式判断。
2. **目标偏小**:bbox 面积 10% 分位 ≈ 0.15%(≈25×25 px),多尺度/小目标是真难点。
3. **类别不平衡**:Hole(破洞)仅占 11.8%,且多为小目标。
4. **提交格式**(官方 `test_result.csv` 表头,实测):
   ```
   image_id,class_id,x_center,y_center,width,height
   ```
   纯检测格式(YOLO 归一化 bbox),**无 score / 无 mask / 无 has_damage 列**;分割与分类只体现在报告评估中。
